# Privacy Policy

Medieval YouTube Automation is a private automation tool operated by the repository owner.

The application accesses the owner's Google Drive files and YouTube channel only after OAuth authorization. It uses this access to locate selected video files, upload them to YouTube, schedule publication, and move successfully processed files between designated Google Drive folders.

The application does not sell, rent, or share Google user data with third parties. OAuth credentials and refresh tokens are stored as encrypted GitHub Actions secrets and are not included in the public repository.

Google user data is used only to perform the automation requested by the account owner. Access can be revoked at any time through the Google Account security settings.

For privacy questions or data-deletion requests, contact: harisnoma20@gmail.com
